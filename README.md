# 🎙️ AI Voice Transcription & Translation

## Overview
This project is an AI-powered voice transcription and translation application built using Streamlit. It converts speech into text, automatically detects the spoken language, translates the content into a selected language, and generates audio output for the translated text.

## Features
- Speech-to-Text Transcription
- Automatic Language Detection
- Multilingual Translation
- Text-to-Speech Audio Generation
- User-Friendly Streamlit Interface

## Technologies Used
- Python
- Streamlit
- Faster-Whisper
- Deep Translator
- gTTS
- SpeechRecognition
